# hermes-branding

Static pages + app logo required by the Google Cloud OAuth consent screen branding section.
Published via GitHub Pages at https://arthuriva.github.io/hermes-branding/

- `index.html` — application home page
- `privacy.html` — privacy policy URL
- `terms.html` — terms of service URL
- `logo.png` — app logo (256px PNG, well under Google's 1 MB / >=120px requirement)

Local preview: `python3 -m http.server` in this folder.
